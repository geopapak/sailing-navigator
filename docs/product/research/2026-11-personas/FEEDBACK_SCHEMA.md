# Μορφή feedback ανά περσόνα

Ένα αρχείο ανά περσόνα: `feedback/P0xx.json`. Ελληνικά στα κείμενα (οι ξένοι γράφουν στα αγγλικά τα `quotes`, με ελληνική απόδοση στο `summary`).

```json
{
  "id": "P0xx",
  "method": "screens | browser",
  "flows_tried": ["01", "07", "10"],
  "scores": {
    "first_impression": 1-5,
    "ease_of_use": 1-5,
    "usefulness_for_me": 1-5,
    "readability_at_sea": 1-5,
    "trust_in_numbers": 1-5,
    "would_use_next_outing": 1-5,
    "would_recommend": 0-10,
    "would_pay": "no | maybe | yes (ποσό/μήνα)"
  },
  "likes": ["…", "…", "…"],
  "problems": [
    { "screen": "07-12", "flow": "07", "what": "…", "why_it_matters_to_me": "…", "severity": "blocker | major | minor | cosmetic" }
  ],
  "confusing_words": ["…"],
  "missing_for_me": ["…"],
  "suggestions": ["…"],
  "quotes": ["μια-δυο φράσεις στο ύφος της περσόνας"],
  "summary": "2–3 προτάσεις"
}
```

Κανόνες:
- Η περσόνα κρίνει μόνο ό,τι θα έβλεπε και θα χρησιμοποιούσε λογικά με τον ρόλο, τη συσκευή, την όραση, τη γλώσσα και την υπομονή της. Ένας αρχάριος δεν ξέρει τι είναι layline· ένας ξένος δεν διαβάζει εύκολα ελληνικά· κάποιος με iPhone mini και γυαλιά πρεσβυωπίας κοιτάζει τα στιγμιότυπα 320 px / «Πολύ μεγάλα».
- Όχι ευγένειες: τα προβλήματα μετράνε περισσότερο από τα καλά λόγια. Κάθε πρόβλημα με αναφορά σε στιγμιότυπο (`NN-MM`) ή ροή.
- Όχι εφευρέσεις: αν κάτι δεν φαίνεται στα στιγμιότυπα/κείμενα ή στον browser, γράψε «δεν το είδα», μην υποθέτεις.
- Τα δεδομένα είναι φανταστικά. Κανένα πραγματικό όνομα, email ή προσωπικό στοιχείο.
